# Claude Notes — Session Journal

Cross-session archive of work done with Claude Code. Each entry = one dated file
(`YYYY-MM-DD.md`): what was done, decisions made, open threads, next steps.

> [!info] Two memory layers
> - **Short status** (where we stopped + next step) lives in Claude's memory -> auto-loaded each session.
> - **Full journal** (this folder) -> a readable/editable archive in Obsidian.
